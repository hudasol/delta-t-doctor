# delta-t-doctor v1.4.0

A redesigned dashboard, static typing and broader tests. The bundled models are unchanged.

## Dashboard

IBM Plex type, a pearl and sakura palette, and a plant schematic that shows where in the energy transfer station each likely cause acts, shaded by probability. Arabic, right to left layout, dark mode and printing are retained.

## Engineering

mypy runs in CI and is clean; CLI commands are covered by end to end tests; pre commit runs ruff and the documentation link checker. See [docs/research/ENGINEERING_REVIEW.md](../research/ENGINEERING_REVIEW.md) for the review behind these changes.
