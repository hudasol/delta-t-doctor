# delta-t-doctor v1.3.0

Adds a preregistered baseline suite and reorganises the repository. The bundled models are unchanged. All results are from simulation; no field accuracy is claimed.

## Baselines

Eight reference models on the same features in three simulated worlds and in zero shot transfer. Plain gradient boosting matches the shipped model on macro AUROC (A: 0.967 against 0.966). The shipped model has the lowest expected calibration error in every world and adds gain intervals, abstention and evidence statements. Details: [docs/research/BASELINES.md](../research/BASELINES.md).

## Layout

Research logs are in `docs/research/`, release notes in `docs/releases/`. `scripts/check_links.py` verifies relative links.
