# Language support (English and Arabic)

The web app and the printable owner report switch between English and Arabic (right-to-left layout, Arabic digits are
kept Latin for consistency with meter exports, numbers format as `ar-AE`).

- Notes are created with `i18n.note(key, **params)`; the API returns `notes` (English) and `notes_ar`.
- Cause names, checks and the disclaimer are returned as `label_ar`, `checks_ar`, `disclaimer_ar`.
- Report endpoints take `lang=en|ar`; the CLI takes `diagnose --html out.html --lang ar`.
- The Arabic font is IBM Plex Sans Arabic (SIL OFL 1.1), bundled so there are no external requests.
